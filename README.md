# AirGrip website

New airgrip.co.in for AirGrip, Jamnagar: brass components made to drawing, plus a standard range of brass cable glands
and accessories.

| Folder | What |
|---|---|
| `site/` | The website: React + Vite, every page pre-rendered to static HTML. Build and deploy: `docs/BUILD.md` |
| `design/` | The locked design (static HTML mock-ups and their generators). The site is generated from it. |
| `docs/` | Requirements, design lock, copy style, SEO plan, open questions, status |

Quick start: `cd site && npm install && npm run dev` (http://127.0.0.1:5175), or `npm run build` for the static site in `site/dist/`.
